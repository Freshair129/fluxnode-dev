FluxNode — Actual Tech Stack (verified against the repo, 2026-07)

This file previously described an earlier proposal (React Flow + FastAPI + Socket.IO +
ffmpeg-next) that was never implemented. The stack below reflects what actually ships.

| Layer               | Technology                                   | Notes |
| ------------------- | --------------------------------------------- | ----- |
| Frontend UI         | React 19 + TypeScript 6 (strict) + Tailwind CSS v4 | `src/features/`, `src/app/` |
| Node / workflow canvas | Custom SVG-based canvas (no React Flow)   | `src/domain/workflow/`, `src/features/workflow/` |
| State management    | Zustand (single store) + Immer for structural updates | `src/store/project-store.ts` |
| Desktop shell        | Tauri v2                                     | `src-tauri/`, IPC via `@tauri-apps/api` |
| Core / video engine  | Rust (Tauri backend), bundled ffmpeg/ffprobe binaries | `src-tauri/src/lib.rs`, `src-tauri/binaries/` (fetched via `scripts/fetch-ffmpeg.ps1`, not committed) |
| AI Copilot / agent layer | Rust action registry + agent loop, local Ollama (default `qwen3.5:4b`), optional in-process llama.cpp (`--features llama`, stub), MCP server (`rmcp`) | `src-tauri/src/action.rs`, `brain/`, `mcp.rs` |
| Media generation     | Pluggable adapter: stable-diffusion.cpp / ComfyUI (image), whisper (transcribe), piper (synth) | `src-tauri/src/media/` |
| Communication        | Tauri IPC (commands/events) — no WebSockets/Socket.IO | |
| Persistence          | `.fluxnode/` project directory (`project.json` + `autosave/` + `thumbnails/` + `proxies/` + `cache/`); localStorage fallback in browser-only dev mode | `src/services/persistence/` |
| Testing              | Vitest | `npm test` |
| Linting              | oxlint (no eslint) | `.oxlintrc.json` |
| Formatting           | Prettier | `.prettierrc` |

See `MASTERPLAN.md`, `STATUS.md`, and `docs/AI Copilot and Media Adapter Design.md` for the
full architecture and current implementation status.
